# Оценка задачи (🤖 Оценить AI)

Оценивает XP/этерны за одну задачу по её названию и описанию, и пытается подобрать проект и/или трек
развития, к которым эта задача явно относится.

## Где

Кнопка "🤖 Оценить AI" в [`TaskModal.tsx`](../../src/components/TaskModal.tsx), над полями XP/Этерны.
Доступна и при создании новой задачи, и при редактировании существующей.

## Файлы

- [`src/utils/aiTaskEstimate.ts`](../../src/utils/aiTaskEstimate.ts) — весь модуль (общее ядро +
  сама эта функция `estimateTaskReward`)
- [`src/components/TaskModal.tsx`](../../src/components/TaskModal.tsx) — UI и вызов

## Как работает

1. По клику собирается вход:
   - **Few-shot примеры** — до 6 уже выполненных задач пользователя (`pickFewShotExamples`),
     приоритет отдаётся задачам того же проекта, что выбран в форме сейчас; описание каждого примера
     обрезается до 150 символов. Если примеров нет — используется только общая рубрика.
   - **Кандидаты для проекта** — названия всех **активных** проектов.
   - **Кандидаты для трека** — названия всех треков, у которых есть хотя бы один этап, вместе с
     их целью и названием **текущего** этапа (не всех этапов — только текущего, так как линковать
     задачу к уже пройденному или ещё не начатому этапу не имеет смысла).
2. Промпт просит вернуть JSON: `{"xp": число, "eternas": число, "projectTitle": строка|null, "trackTitle": строка|null}`.
   - Шкала XP привязана к порогам уровней персонажа (300/700/1200/.../8000): мелкая задача (15-30 мин)
     — 10-30 XP, средняя (часы) — 30-80 XP, крупная (день+) — 80-150 XP. Этерны ≈ ¼ от XP.
   - Если задача явно относится к проекту/треку из списка кандидатов — возвращается их название
     (только голое, без цели/этапа, которые в списке идут через запятую как справочная информация).
     Если связь неочевидна — `null`.
3. Ответ парсится, `projectTitle`/`trackTitle` резолвятся в реальные `id` через `titleMatches` по
   спискам `projects`/`tracks`, которые уже есть в компоненте.
4. Применяется **всегда** (перезаписывает то, что уже выбрано в форме) — если найдено совпадение:
   - `xp`/`eternas` — подставляются в поля формы.
   - `projectId` — подставляется, если совпал проект.
   - `trackLinks` — если совпал трек, добавляется связка `{trackId, stageId: текущий этап трека}`,
     заменяя прежнюю связку с этим же треком, если она уже была (остальные треки не трогаются).
   - Toast показывает, что именно подставилось: `AI: 45 XP · 11 ✦ · проект «Диссертация»`.
5. **Кэш на неизменный ввод.** Повторный клик с тем же `title`+`description` не делает новый запрос —
   применяется прошлый результат (ключ кэша — `title + ' ' + description`, хранится в `useState`
   компонента, живёт пока открыта модалка).

## Пример

Вход: title = "Исправить правки научного руководителя", проект "Диссертация" есть в списке кандидатов.
Выход: `{xp: 45, eternas: 11, projectTitle: "Диссертация", trackTitle: null}` — поле "Проект" в форме
подставится само.

## Ограничения

- Матчинг проекта/трека — по точному или префиксному совпадению названия (`titleMatches`), не по
  смыслу постфактум — если модель ошиблась в названии сильнее, чем просто дописала лишний текст в
  конец, совпадение не найдётся и поле останется как было.
- Оценка XP не знает о размере проекта/трека, только о размере самой задачи — крупные многомесячные
  инициативы разумно заводить как отдельные подзадачи, а не одной строкой (см. также
  [track-plan.md](./track-plan.md) про аналогичное ограничение у планов трека).
