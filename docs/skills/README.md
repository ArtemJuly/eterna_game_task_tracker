# AI-навыки Этерны

В приложении пять AI-функций поверх одной и той же связки: `fetch` → `https://api.proxyapi.ru/anthropic/v1/messages`
(Anthropic-совместимый прокси) → модель **claude-haiku-4-5**. Никакого фреймворка (LangChain/LangGraph)
и никакого бэкенда — один прямой запрос из браузера на каждое действие.

## Общее ядро — [`src/utils/aiTaskEstimate.ts`](../../src/utils/aiTaskEstimate.ts)

Все навыки переиспользуют из этого файла:

- **`callAiForText(systemPrompt, userPrompt, maxTokens, apiKey)`** — сам сетевой вызов: собирает
  запрос, обрабатывает ошибки (нет сети, невалидный ключ, битый ответ) и возвращает текст ответа модели.
  Единая точка, где что-либо может пойти не так — здесь же и вся обработка ошибок.
- **`extractJson(text)`** — снимает возможные ```json-фенсы вокруг ответа перед `JSON.parse`.
- **`AiEstimateError`** — единый класс ошибок для всех навыков; в UI ловится через
  `err instanceof AiEstimateError` — если да, показывается его `.message` (понятный текст), если нет —
  общий фолбэк-текст и `console.error` для диагностики.
- **`buildRewardRubricLines()`** — общая шкала XP/этерн и правила сопоставления проект/трек,
  используется и оценкой задачи, и разбором списка (чтобы цифры не расходились между двумя похожими фичами).
- **`titleMatches(candidateTitle, aiValue)`** — терпимое сравнение названий: модель иногда возвращает
  не голое название, а название с довеском ("Трек, цель: ..., этап: ...") несмотря на инструкции —
  сравнение допускает `aiValue.startsWith(candidateTitle)`, а не только точное совпадение.

## Общие принципы, которые соблюдают все пять навыков

1. **Только по клику.** Ни один навык не вызывается автоматически (при открытии модалки, при вводе
   текста и т.п.) — только явное нажатие кнопки. Это осознанное решение ради контроля над расходами
   на API.
2. **Агент предлагает — человек подтверждает.** Ни один результат не применяется вслепую: оценка XP
   попадает в редактируемые поля, план дня/спринта — в редактируемый список (можно убрать пункт
   крестиком или добавить свой через поиск), план трека — в обычные этапы, которые можно
   переименовать/удалить как любые другие.
3. **`temperature: 0`** во всех запросах — детерминированность важнее творческого разнообразия для
   личного трекера, где повторный клик на тот же ввод должен давать стабильный результат.
4. **По умолчанию — `null`/ничего не делать.** Там, где агент сопоставляет с проектом/треком, правило
   одно: если нет явной, недвusмысленной связи — вернуть `null`, а не притягивать за уши (это отдельно
   потребовалось усилить в промпте после того, как в тестах "покупка корма коту" один раз прилипла
   к проекту "Здоровье").
5. **Ключ API** вводится в Settings и хранится только в `localStorage` браузера — не коммитится, не
   уходит никуда, кроме proxyapi.ru.
